# 분리배출 로봇팔 (recycle-sorter-robot)

> "페트병만 치워줘" — 한국 분리배출 기준을 이해하고, 집고, 설명하는 데스크톱 로봇팔

로보틱스·코딩·하드웨어를 전혀 모르던 비전공자가 35개 스텝을 따라
분리배출 로봇을 처음부터 끝까지 직접 만드는 과정을 기록하는 레포입니다.

## 목표 데모

책상 위에 섞인 재활용품을 카메라로 알아보고, 사람의 말을 이해해
한국 분리배출 기준에 맞는 통으로 옮기고, 왜 그렇게 했는지 설명합니다.
라벨이 붙은 페트병처럼 지금 배출하면 안 되는 물체는 남겨두고 이유를 알려줍니다.

## 하드웨어

- 로봇팔: myCobot 280 Jetson Nano (6축)
- 엔드이펙터: 그리퍼, 흡착 펌프
- 서버: Ubuntu 24.04 · NVIDIA RTX 4090
- 개발: MacBook (SSH, 원격 데스크톱)

## 소프트웨어 (예정)

ROS 2 Jazzy · MoveIt2 · Gazebo · Ultralytics YOLO · LangGraph · OpenAI API
